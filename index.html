Before electric telegraphs · The problem

A message could not outrun a horse

Imagine needing to tell someone in another town that a ship had arrived, a family member was safe, or the weather was changing. Letters travelled with riders and ships, so the news could take days or weeks. Signal flags and towers were quicker, but each station had to see the next one. Inventors wanted a message that could travel farther than eyes could see.

How a wire can carry a message

A battery supplies electricity; a key opens and closes the circuit; a receiver at the far end notices each change. Those two states—on and off—can make a pattern. The clever part is agreeing what the pattern means.

For grown-ups: family guide

Start with the game, then add the controller one safe piece at a time. A working BOOT button is already a complete project.

Before switching on

  • An adult should flash the board and check the wiring.
  • Unplug USB before changing wires, and never connect 5 V to an ESP32 GPIO pin.
  • Stop and unplug if the board gets hot, smells unusual, resets repeatedly, or disconnects.

A relaxed first session

  1. Explore the game with no hardware.
  2. Try E (dot), T (dash), then SOS.
  3. After the adult check, try the ESP32’s built-in BOOT key.
  4. Add light, sound, a button, or a dial only when you are ready for the next experiment.

Privacy and Wi-Fi

The game has no account, analytics, cloud service, or chat. The ESP32’s local network is Dotto’s Dash; its password is dottodash. It does not need internet. Treat the optional home-Wi-Fi form as an adult setup task, and use only a trusted network.
