Before electric telegraphs · The problem

A message could not outrun a horse

Imagine needing to tell someone in another town that a ship had arrived, a family member was safe, or the weather was changing. Letters travelled with riders and ships, so the news could take days or weeks. Signal flags and towers were quicker, but each station had to see the next one. Inventors wanted a message that could travel farther than eyes could see.

How a wire can carry a message

A battery supplies electricity; a key opens and closes the circuit; a receiver at the far end notices each change. Those two states—on and off—can make a pattern. The clever part is agreeing what the pattern means.

How computers think: two signals are enough

Dotto’s whole alphabet is built from two signals. That is not a trick to make the game easy — it is the idea every computer in the world runs on.

A machine is bad at measuring something exactly, but very good at telling two clearly different states apart. So engineers use exactly two and call them 1 and 0. One of those choices is a bit, short for binary digit.

One bit can only say two things: yes or no, dot or dash, E or T. But every bit you add doubles how much you can say, and that grows fast:

  • 1 bit → 2 messages E and T, the first row of the tree
  • 2 bits → 4 I, A, N, M
  • 3 bits → 8 S, U, R, W, D, K, G, O
  • 8 bits → 256 enough for every letter, digit and punctuation mark

That doubling is exactly the walk you take through the Morse tree: each dot or dash halves the letters that are still possible.

Build a byte

Eight bits in a row are called a byte. Each place is worth double the one to its right. Switch some bits on, add up their values, and see which character that number stands for.

Computers agreed one shared list of which number means which character. It is called ASCII: A is 65, B is 66, and a space is 32.

So is Morse code binary? Almost, and the difference is worth knowing. A byte is always exactly eight bits, so a computer knows where one character ends and the next begins. Morse letters have different lengths — E is one signal and Z is four — so Morse also needs the silence between signals to show where a letter stops. Morse really uses three things: dot, dash and pause.

Inside Dotto’s controller everything really is bits. The button pin reads 1 while the button is open and 0 while you hold it down. Each colour is made from thousands of fast 1s and 0s per second. The sound travels to the speaker amplifier as binary numbers. Even this page arrived as bits: the ESP32 keeps the whole game as about a million of them.

For grown-ups: family guide

Start with the game, then add the controller one safe piece at a time. A working BOOT button is already a complete project.

Before switching on

  • An adult should flash the board and check the wiring.
  • Unplug USB before changing wires, and never connect 5 V to an ESP32 GPIO pin.
  • Stop and unplug if the board gets hot, smells unusual, resets repeatedly, or disconnects.

A relaxed first session

  1. Explore the game with no hardware.
  2. Try E (dot), T (dash), then SOS.
  3. After the adult check, try the ESP32’s built-in BOOT key.
  4. Add light, sound, a button, or a dial only when you are ready for the next experiment.

Privacy and Wi-Fi

The game has no account, analytics, cloud service, or chat. The ESP32’s local network is Dotto’s Dash; its password is dottodash. It does not need internet. Treat the optional home-Wi-Fi form as an adult setup task, and use only a trusted network.
