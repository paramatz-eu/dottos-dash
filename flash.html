Put Dotto on a real board

Flash the ESP32 from your browser

No software to install and no ESPHome needed. Plug the board into this computer with a USB cable, press one button, and wait.

Adult helper for USB · Chrome or Edge on a computer · Ages 10+

Before you start

Three things to check

  1. Use Chrome or Edge on a computer. Firefox and Safari cannot talk to a USB board, and phones cannot do this at all. A phone is only used later, to play the game.
  2. Use a data USB cable. Some cables only carry power. If the board never appears in the list, a charge-only cable is the usual reason.
  3. Use the one Dotto's Dash build. It works before any sound is wired, with a passive piezo, with a MAX98357A speaker, or with both together.
Safety: unplug USB before changing any wire, and never connect 5 V to an ESP32 GPIO pin. Leave the board plugged in for the whole install; unplugging part-way can leave it without working firmware.

Step 1

Install Dotto's Dash

One build Start here

Works with no sound part, a passive piezo on GPIO27, a MAX98357A speaker, or both sound parts together.

This browser cannot flash a board. Open this page in Chrome or Edge on a computer. Flashing needs a secure connection (https). Open the published page rather than a local file.

A window will ask which serial port to use. If the list is empty, try another USB cable or another port first. If the board still does not appear, hold BOOT, tap EN, keep holding BOOT for two seconds, release it, and try again.

Step 2

Play it

When the install finishes, the board restarts and makes its own Wi-Fi network called Dotto's Dash, with the password dottodash.

  1. Join that network with a phone, tablet or computer.
  2. Open http://192.168.4.1/ — type it exactly, with http:// and not https://.
  3. The whole game loads from the board itself. No internet is used from here on.

On Android the network may say No internet. Choose Stay connected, close the notice, then open the address in Chrome.

The built-in BOOT button already works as a Morse key, so there is something to play with before any wiring. To add the light, key, dial and sound one step at a time, follow the build lesson.

Later

Updating without a cable

Only the first install needs USB. For a later version, join the Dotto's Dash network, open the game, and use For adults: update firmware at the bottom of the page. Choose an -ota.bin file there — never a -factory.bin.

Whoever updates the board has to be near it. This is a deliberate part of the design: the board is never reachable from the internet.
