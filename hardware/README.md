# Hardware design sources

No hardware CAD or manufacturing source is published in this directory yet.
When it is added, place PCB, enclosure, wiring and manufacturing source here
and license it under [CERN-OHL-W-2.0](../LICENSES/CERN-OHL-W-2.0.txt).

Include the following notice in each design or in the design's accompanying
`README`:

```text
Copyright 2026 Dotto's Dash contributors
SPDX-License-Identifier: CERN-OHL-W-2.0
Source Location: https://github.com/paramatz-eu/dottos-dash
```

Keep manufacturer component datasheets, generated fabrication output and
third-party libraries under their own terms. A hardware revision should also
identify this source location on the PCB or in accompanying documentation.
