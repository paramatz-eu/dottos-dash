What are we building?

The ESP32 is a tiny computer. It notices a button or dial, turns that into Morse code, then answers with coloured light and sound.

finger or dial → ESP32 input pin → Morse program → light and sound

short press = dot        long press = dash
turn left = dot          turn right = dash
pause 1.2 seconds = decode a letter

Safety first

  • An adult flashes the board and checks wires before USB is connected.
  • Unplug USB before moving a wire.
  • Use USB power only while learning. Never use wall power, mains electricity, unknown supplies, or oversized batteries.
  • ESP32 GPIO pins are 3.3 V only. Never connect 5 V to a GPIO pin.
  • Use the named HW-479 RGB module, or add a resistor to every channel of a bare LED.
  • If the board gets hot, smells odd, or disconnects: unplug it now and inspect the wiring with the adult helper.

Reconnect USB. The light should briefly glow blue-green. Later, dots are cyan, dashes are orange, a recognised letter is green, and an unknown code is red.

What is an RGB light?

RGB means red, green and blue. The ESP32 rapidly switches each colour channel on and off using PWM (pulse-width modulation). Your eyes blend those fast flashes into colours. A common-cathode LED has one shared path to GND and three separately controlled colour paths.

Stop if needed: do not guess from wire colours. This project expects a common-cathode HW-479 module. A common-anode LED or a module with a different pin layout needs different wiring and firmware.

Step 2

Make the Morse button

Start without wiring: the ESP32 DevKit's BOOT button is already a Morse key after flashing. Releasing it records a dot or dash; with RGB and a piezo connected, feedback begins when it is pressed. Do not hold BOOT while resetting or flashing.

Add the external button below when you want a larger key on the breadboard.

Button sideESP32 pin
One sideGPIO13
Other sideGND
GPIO13 ───────── [ push button ] ───────── GND

Test

  1. Quick tap: cyan means dot.
  2. Hold for about half a second: orange means dash.
  3. Tap once, wait: . becomes E.
  4. Make ..., wait: it becomes S.
Why is there no resistor on the button?

The ESP32 uses an internal pull-up resistor. When the button is open, GPIO13 reads HIGH. Pressing the button joins it to GND, so it reads LOW. The program measures the LOW time. It also ignores tiny switch wiggles at first contact; that is debouncing.

Four-leg breadboard buttons have two joined legs on each side. Use one leg from each side across the centre gap. Two legs from the same side are already connected.

Test

Turn left for a dot and right for a dash. If it feels backwards, unplug USB and swap only the CLK and DT wires.

How can a dial know left from right?

An encoder sends two click signals. One changes just before the other; that order tells the ESP32 which way it turned. This two-signal idea is called quadrature.

Use a passive piezo. The firmware makes its tone by changing the GPIO signal thousands of times per second. A passive piezo bends a tiny amount, moves air, and makes sound.

Option B: MAX98357A and a small speaker

Use this instead of the piezo for louder sound. Flash the other firmware first.

The speaker connects only to the amplifier, never directly to an ESP32 pin. BCLK, LRC, and DIN are the three digital I2S sound signals; the MAX98357A turns them into speaker power.

Invent your own experiment

  1. Send E (.), T (-), then SOS (... --- ...).
  2. Predict the light colour before pressing the button, then test your prediction.
  3. On paper, decide which two wires change the encoder direction.
  4. With an adult, open the shared firmware. Find GPIO13 and the 1200 ms pause.

Every successful test is a small scientific experiment: predict, change one thing, observe, and write down what happened.
